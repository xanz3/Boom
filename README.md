## Установка

**Windows:** скачайте `BoomSetup.exe` и запустите. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». Обновления потом приходят сами.

**Android:** скачайте `Boom.apk` на телефон и откройте. Разрешите установку из неизвестных источников, если телефон попросит.

При первом запуске введите адрес сервера, который вам дали (например `1.2.3.4:5050`), и войдите или зарегистрируйтесь.

- 🎙 Голосовые каналы, рация (push-to-talk) — работает даже в игре, шумоподавление

- 🎨 8 тем и 10 языков
